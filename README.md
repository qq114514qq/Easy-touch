Easy Touch – Screen touch has never been this effortless!

This software turns your TV into a touchscreen TV. All you need is the built-in camera on your laptop or a separately purchased camera. There is no restriction on TV brand or model. Even a computer with just 4GB of RAM and an Intel i3 processor can use the touch functionality relatively smoothly. The user interface is built with WinUI 3. When used with software similar to Seewo Whiteboard, it enables smooth writing. This is especially friendly for users on a budget.

System requirements: Windows 10 or above, x64 architecture. The project requires Python (the packaged version does not). It is written in Python and C# / C++, with assistance from DeepSeek AI.
